title: Merging Data with ABISMAL at NERSC
---

[ABISMAL](https://github.com/rs-station/abismal) is a merging program for X-ray crystallography data recorded at LCLS and other XFELs. 
It uses deep learning and Bayesian inference and supports data processed in the CCTBX XFEL GUI used at MFX. 
LCLS maintains an ABISMAL installation at NERSC. 
Check the [ABISMAL Category](https://discourse.rs-station.org/t/running-abismal-on-nersc/187) on the RS-Station Forum for the latest info on running ABISMAL at NERSC.
